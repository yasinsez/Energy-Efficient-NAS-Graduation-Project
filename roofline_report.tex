\section*{Pre-Execution Scheduling \& The Token Count Prerequisite}
In production LLM serving, latency predictors must operate \textbf{strictly pre-execution} using launch configurations: cluster parallelism (\texttt{tp}, \texttt{pp}, \texttt{dp}, \texttt{num\_gpus}) and request budgets (\texttt{batch\_size}, \texttt{output\_tokens}). Post-execution telemetry is strictly excluded.

\vspace{-0.3em}
\noindent \textbf{The Token Prerequisite (Imai et al., Section A.4)}: The analytical Roofline Model (RLM) calculates hardware ceilings from input and output tokens:
\begin{equation}
    T_{\text{roofline}} = T_{\text{prefill}}(\text{input\_tokens}) + \text{output\_tokens} \times T_{\text{decode\_step}}(\text{batch\_size})
\end{equation}
While prompt length is known pre-execution, output length is dynamic. As acknowledged by Imai et al. (Appendix A.4): \textit{``In practical application, the generation length is not predetermined... To accurately model inference latency in real world scenarios, we must consider predicting the generation length based on the input prompt.''}

\vspace{0.1em}
\noindent \textbf{Methodological Analysis: Single-Model Benchmark Artifact vs. Cross-Model Reality}:
\begin{itemize}
    \setlength\itemsep{0.03em}
    \item \textbf{The Single-Model Confound (Why Trees Treat RLM as Tokens)}: In a fixed-model benchmark (Qwen3-14B) evaluated over discrete prompt lengths (512 vs.~2048), model parameters ($N_{\text{params}}, d_{\text{model}}, L$) and hardware ceilings are constant. Consequently, the analytical roofline $T_{\text{roofline}}$ is a strictly monotonic mathematical transform of \texttt{input\_tokens}. Non-linear tree ensembles (RF/GB) split either feature identically, yielding an identical $R^2 = 0.9997$ (MSE $91.2$ vs.~$87.8$). Within this single-model grid, RLM adds no distinct predictive signal beyond a binary prompt indicator.
    \item \textbf{Why the Roofline Model Is Essential Across Models}: In production serving across heterogeneous model families (e.g., 1.3B to 27B), a raw scalar \texttt{input\_tokens} carries \textbf{zero architectural context}---512 tokens induces orders-of-magnitude different compute/memory load on a 1.3B vs.~a 27B model. The analytical Roofline Model bridges this gap by grounding predictions in model FLOPs, tensor dimensions, and hardware bandwidth.
    \item \textbf{Linear Inductive Prior}: For linear regressors that cannot learn non-linear decision boundaries, RLM provides a meaningful physical inductive bias, reducing MSE by 45\% ($69038 \to 37921$, $R^2 = 0.7879 \to 0.8844$) compared to raw token counts.
    % \item \textbf{Parallelism Scaling}: Unscaled RLM assumes single-GPU SXM ceilings. Scaling analytical ceilings by TP, DP (partitioned batch $B/\text{DP}$), and PP degrees improves physical correlation ($r = 0.85 \to 0.94$) and lowers linear regression MSE from $37921$ to $32339$.
    % \item \textbf{Generalization Collapse (GroupKFold)}: Near-perfect accuracy ($R^2 = 0.9997$) in standard CV is an artifact of discrete cell memorization (10 identical replicates per cell). Testing on unseen parallelism or conditions via \textbf{GroupKFold} drops accuracy to \textbf{$R^2 = 0.45 - 0.65$}. However, RLM provides a vital inductive bias when extrapolating to unseen sequence lengths where trees collapse ($R^2 = -0.26$).
\end{itemize}

\section*{Key Conclusions for Deployment \& Next Steps}
\begin{itemize}
    \setlength\itemsep{0.02em}
    \item \textbf{Single-Model Scope}: For isolated single-model deployments where prompt length is known pre-launch, empirical tree models achieve maximum accuracy using raw prompt tokens without analytical profiling.
    \item \textbf{Cross-Model Serving}: The Roofline Model's primary value lies in cross-model and cross-hardware serving matrices, where physical parameter scaling ($O(\text{FLOPs})$, tensor sizes) is mandatory.
    \item \textbf{Value for Linear Estimators}: RLM provides an effective inductive physics prior for linear estimators ($R^2 = 0.7879 \to 0.8844$, reducing MSE by 45\%).
    % \item \textbf{Out-of-Distribution Generalization}: RLM provides inductive bias when extrapolating to unseen sequence lengths where purely empirical tree models collapse ($R^2 = -0.26 \to +0.37$).
    \item \textbf{Experimental Next Steps}: Validate across continuous sequence lengths (dynamic RAG / chatbot traces) rather than fixed 2-point grids, and test multi-node scaling across 32B/70B architectures.
\end{itemize}

\section*{\large Multi-GPU Benchmarking \& Replication Architecture: BSC MareNostrum 5 (MN5)}
\vspace{-0.3em}
\noindent \textbf{Execution Overview}: To empirically replicate and scale the Roofline-driven latency prediction methodology of Imai et al., benchmarks are conducted on the \textbf{Barcelona Supercomputing Center (BSC) MareNostrum 5 Accelerated Partition} (NVIDIA H100 SXM, 4 GPUs/node). The benchmark matrix combines the 4 original lightweight models (1.3B--2.7B) with 2 production-scale models (14B--27B) across both \textbf{vLLM} and \textbf{Triton Inference Server}, scaling from single-GPU up to 8 GPUs (2 nodes) under tensor, pipeline, and data parallelism.
